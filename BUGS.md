# Bugs — Gritted Teeth Lifestyle

Living bug list maintained by **Phone Claude**. New bugs reported from mobile get appended here so PC Claude (or you) can pick them up without context switching.

**Conventions**
- Status: `OPEN` · `IN PROGRESS` · `FIXED`
- Severity: `P0` blocker · `P1` major · `P2` minor · `P3` polish
- Area: `fitness` · `diet` · `shared` · `ui` · `build`
- Each bug has a stable ID (`BUG-001`, etc.) so commits/PRs can reference it.
