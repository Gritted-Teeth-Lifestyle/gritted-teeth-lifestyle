### Task B — R16 holiday detection

Create `lib/exp/holidays.js` exporting:

```
getHolidayMultiplier(date, userDOB) -> 1.5 | 1.0 | 0.5 | 0
```

The function returns the holiday multiplier for the given local date per R16's three-tier list:

**Tier 1 — major (×1.5):**
- User's birthday (`date.month === userDOB.month && date.day === userDOB.day`)
- New Year's Day (Jan 1)
- Christmas (Dec 25)

**Tier 2 — feast (×1.0):**
- Independence Day (Jul 4)
- Thanksgiving (4th Thursday in November)

**Tier 3 — federal (×0.5):**
- MLK Day (3rd Monday in January)
- Presidents' Day (3rd Monday in February)
- Memorial Day (last Monday in May)
- Juneteenth (Jun 19)
- Labor Day (1st Monday in September)
- Columbus Day (2nd Monday in October)
- Veterans Day (Nov 11)

Total 11 federal holidays + birthday = 12 possible holiday days/yr.

**Stacking rule:** if two trigger on the same day (e.g., birthday on Christmas), apply the higher tier only — no addition.

**Handle DOB unset:** if `userDOB` is `null`/`undefined`, skip the birthday check (return 0 if no other holiday matches).

**Use local date getters** (`date.getFullYear()`, `date.getMonth()`, `date.getDate()`) — not UTC. Spec decision: scope is local-machine, no server roundtrip.

Add tests at `__tests__/exp/holidays.test.js` covering:
- Each Tier-1 holiday (Jan 1, Dec 25, birthday) returns 1.5
- Each Tier-2 holiday returns 1.0
- Each Tier-3 holiday on its computed date returns 0.5 — verify with at least 2026's specific dates
- Non-holiday days return 0
- DOB undefined: holiday-by-date checks still work; birthday returns 0
- Stacking: birthday on Christmas returns 1.5 (not 3.0, not 2.5)
- Edge case (Feb 29 leap-year birthday in non-leap-year): document chosen behavior in test (treat as Feb 28 OR skip; pick one — this IS a discretion question, **route to blocker**)
